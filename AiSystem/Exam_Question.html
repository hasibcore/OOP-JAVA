ChatGPTService is a software component that handles AI text generation.

When generating text, it prints: "Connecting to ChatGPT API to process Prompt: P", where P is a prompt (String).

GeminiService is another software component that handles AI text generation.

When generating text, it prints: "Connecting to Gemini API to process Prompt: P", where P is a prompt (String).

 2

CodeEditor is a software that manages developer interactions and executes user prompts.

When a prompt is responded to, it prints "Connecting with AI models for prompt: P", where P is a prompt (String), and then immediately triggers text generation for the AI service.

 2

Design Constraint: The system must be designed so that new AI services (such as ClaudeService or CopilotService) can be added in the future without modifying the CodeEditor class. To achieve this, CodeEditor must not instantiate ChatGPTService or GeminiService directly, and it must not use if/else statements to choose between them. The specific AI service must be assigned when a CodeEditor object is created.

 5

Implement this entire scenario using the necessary object-oriented principles (classes and interfaces). Use only System.out.println for method implementations. Pass P as a method parameter (String). Avoid code duplication.

Demonstrate your design in the main method by:

  1. Creating a CodeEditor configured to use ChatGPTService, and responding to a prompt.
  2. Creating a separate CodeEditor configured to use GeminiService, and responding to a different prompt.
